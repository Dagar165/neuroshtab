# Нейроштаб

Интерактивный практикум по работе с нейросетями для вожатых и экспертов фестиваля «Из лета в лето».
Один самодостаточный HTML-файл: без сборки, без зависимостей, без сети.

**Ведёт:** Сергей Фенчин, Новосибирск · 3D-моделирование в Blender для подростков.

## Что это

Страница — не презентация, а **пульт у участника в руке**. Ведущий говорит со сцены, участник со своего телефона дважды уходит в свою нейросеть и возвращается:

1. копирует заведомо сырой запрос → получает вежливый бесполезный ответ;
2. собирает ТЗ по пяти рычагам → копирует → получает второй ответ на ту же задачу;
3. сравнивает два ответа в своём чате и ищет в них брак.

Разница между двумя ответами и есть содержание мастер-класса.

## Регламент — 28 минут

| Этап | Время | Что происходит |
|---|---|---|
| Раздача | 3 мин | участники берут номера миссий 1–8 |
| Сырой запрос | 5 мин | копируют, уходят в нейросеть, возвращаются |
| Пять рычагов | 4 мин | блок ведущего: цель, контекст, рамки, формат, проверка + исходник |
| Сборка | 7 мин | собирают ТЗ тапами, копируют, уходят второй раз |
| Разбор | 6 мин | сравнивают два ответа, чек-лист брака, команда на правку |
| Финал | 3 мин | одна мысль и ссылки |

## Восемь миссий

Под роли фестиваля: старший вожатый, вожатый, руководитель смены, методист, медиацентр, эксперт, организатор, руководитель проекта.

**У миссий 03, 06 и 07 есть исходный текст** (жалоба родителя, заявка команды, инструкция для вожатых). Он намеренно **не** прикладывается к первому, сырому запросу — чтобы участник увидел, как модель сочиняет несуществующий документ. Ко второму, собранному запросу исходник уезжает автоматически.

## Устройство файла

Всё в одном `.html`: разметка, стили и логика. Правится обычным текстовым редактором.

- `MISSIONS` — данные восьми миссий: сырой запрос, типичный ответ, по два варианта на каждый рычаг, демо-ответ, исходник.
- `WEAK` — общие слабые формулировки («как обычно»), одни на все миссии.
- `LEVERS` / `LEVER_TEXT` — пять рычагов.
- `STAGES` — этапы, их бюджет времени и подсказки ведущему.
- `buildPrompt()` — сборка запроса; исходник добавляется здесь.
- `S` — состояние, сохраняется в localStorage, чтобы уход в нейросеть и возврат не сбрасывали прогресс.

## Режим ведущего

Кнопка «Ведущий» в шапке. Показывает подсказку под текущий этап и секундомер. На экране участника не нужна.

## Требования к площадке

- Телефон у каждого, вертикально. Ноутбуки не нужны.
- Wi-Fi нужен участникам только чтобы открыть свою нейросеть. Сама страница работает офлайн.
- Хостинг по **https** обязателен: копирование в буфер обмена по http и с локального файла браузеры режут.
- У кого нейросети под рукой нет — работает в паре с соседом.

## Что проверить перед выступлением

- Открываются ли Алиса / GigaChat / DeepSeek с телефона без VPN — подписи в блоке «где это делать дома» не сверялись.
- QR ведёт на https-адрес, а не на файл.
